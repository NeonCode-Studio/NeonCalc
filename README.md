# Neoncode Calc

Neoncode Calc is a command-line calculator written in C++. It provides core arithmetic operations designed for integration into terminal environments or educational purposes.

## Requirements

- A C++ compiler supporting C++11 or later (e.g., GCC, Clang, MSVC)
- Make or CMake (optional, depending on the build configuration)

## Compilation

To compile the source code manually using GCC, run the following command in the terminal:

```bash
g++ -std=c++11 main.cpp -o neoncode_calc
```

## Usage

Run the compiled executable from the command line:

```bash
./neoncode_calc
```

Follow the on-screen prompts to perform calculations.
